# Python File Handling & Automation

## Alfido Tech - Python Developer Internship

### Task 1: File Handling & Automation

## Project Overview

This project demonstrates Python file handling, file automation, and exception handling.

The application provides a simple menu-driven system for performing operations on TXT and CSV files.

## Features

- Create and write TXT files
- Read TXT files
- Append data to TXT files
- Create CSV files
- Read CSV files
- Rename files
- Move files
- Delete files
- Handle file-related errors using exception handling
- Menu-driven command-line interface

## Technologies Used

- Python
- CSV Module
- OS Module
- Shutil Module
